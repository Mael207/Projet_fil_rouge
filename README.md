# Projet Fil Rouge - R109
## Description du projet

Ce projet consiste à la création d'une page web utilisant les langages HTML et CSS à partir d'une maquette graphique.
Cette page web est responsive (ordinateur, tablette, téléphone) avec pour objectif de respecter le plus fidèlement la maquette d'un point de vue typographique et pratique.

## Lien vers le site (GitHub Pages)
**[Visualiser le site en ligne](https://mael207.github.io/Projet_fil_rouge/)**

## Langages et outils

* **HTML5** : Structuration sémantique du contenu.
* **CSS3** : Mise en page
* **Google Fonts** : Intégration des polices
* **Font Awesome** : Intégration des icônes vectorielles.
